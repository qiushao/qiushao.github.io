QSNote介绍

2026-11-09 QSNote QSNote 评论

起源

QSNote 起源于我自己的写作需求。我平时有记笔记，写博客，写电子书，记录待办事项的习惯。之前这些都是使用不同的应用来进行的，但各种应用都或多或少有些不太满足自己的需求，比如说：

  • 记笔记： VNote。VNote 的整本笔记导出功能没有目录，笔记目录里有应用配置文件目录，新版本界面越来越花里胡哨。
  • 写博客： vscode + hexo。 vscode Markdown 编辑体验不好。hexo 速度慢，安装配置复杂，还要敲命令。
  • 写电子书： gitbook。多年前用的是命令行的 gitbook，要手动编辑 SUMMARY.md，章节有变化时非常麻烦，生成的电子书格式也是一言难尽。
  • 待办事项：滴答清单。界面越花里胡哨太复杂。

之前就一直想自己重新造个轮子，以便满足自己的各种需求，奈何能力有限，尝试了几次之后，就不了了之了。 但从 claude code, codex 发布之后，感觉限制我们的只有想象力了，于是趁着最近工作比较悠闲，便开始了造轮运动。 前后大概花了一个月的业余时间完成了核心功能，再花一个月边使用，边把各种细节打磨一遍。目前这个状态自我感觉已经很满意了。

特色功能

QSNote 的一些特色功能：

  • 使用 c++ QT 开发，性能流畅
  • 本地目录管理 Markdown 文件，数据掌握在自己手中，数据的备份，同步可以使用 git, iCloud 云盘, 坚果云或你熟悉的文件同步工具。
  • 除基本 Markdown 语法支持外，还支持丰富的图表，公式等。
  • 支持多种类型笔记本：普通笔记本，静态博客，电子书，待办事项。
  • 静态博客，电子书写作，预览，发布一条龙。
  • 各种格式的文本文件语法高亮
  • 贴心的各种图表公式样板
  • 电子书章节自动编号
  • 暖心护眼的主题配色
