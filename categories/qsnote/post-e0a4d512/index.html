Markdown 是什么

Markdown 使用简单的文本标记表达标题、列表、引用、链接和代码。源码本身可以直接阅读，也方便用 Git 保存修改记录。在 QSNote 中，可以切换到分屏模式，一边输入源码，一边查看排版。

本文介绍日常写作的基础语法，扩展语法见 Markdown扩展语法，流程图和时序图等见 Markdown图表。代码框展示的是输入内容，复制时保留其中的空行和缩进。

标题

在行首使用一到六个 #，后面加一个空格。数量越多，层级越深。

写文章时按内容层次使用标题，不要仅为了调整字号而跳级。QSNote 会根据标题生成大纲，长文章可以通过大纲定位章节。

QSNote 的本地链接以当前文档所在目录为基准，../ 表示上一级目录。文件名、扩展名和相对目录都需要与实际文件一致。

标题可以作为跳转目标，例如中文标题 图片 对应 #图片，英文标题 Usage Example 对应 #usage-example。修改标题后，也要更新指向它的链接。
